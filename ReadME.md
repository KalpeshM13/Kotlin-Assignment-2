# Kotlin Assignment 2 ![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

This repository contains solutions for the **Module 4 Assignment: OOPs in Kotlin** from the TuteDude App Development Course.

## Overview

This assignment focuses on understanding and implementing the core principles of **Object-Oriented Programming (OOP)** using Kotlin. The solutions are organized into separate packages based on the assignment sections for better structure and readability.

## Project Structure

The project is organized into packages, with each package representing a section of the assignment.

```text
src/
└── main/
    └── kotlin/
        ├── sectionA/
        ├── sectionB/
        ├── sectionC/
        ├── sectionD/
        ├── sectionE/
        └── miniAssignment/
```

## Sections Covered

### Section A: Basic OOP Practice
- Creating classes and objects
- Defining properties and functions
- Working with constructors

### Section B: Encapsulation
- Private properties
- Getter and setter functions
- Data validation and controlled access

### Section C: Inheritance
- Base and derived classes
- Reusing code through inheritance
- Extending existing functionality

### Section D: Interfaces
- Creating interfaces
- Implementing interface methods
- Understanding abstraction through interfaces

### Section E: Polymorphism
- Method overriding
- Runtime polymorphism
- Working with collections of base-class references

### Mini Assignment
- Library Management System
- Book and Library classes
- Adding, removing, and displaying books
- Applying OOP concepts in a practical project

## Outputs

The output for each question is included within its respective section package, making it easy to review both the implementation and the result.

## Technologies Used

- Kotlin
- IntelliJ IDEA

## Assignment Details

This repository was created as part of the **Module 4 Assignment: OOPs in Kotlin** in the TuteDude App Development Course.

The goal of this assignment is to strengthen the understanding of OOP concepts through hands-on programming exercises and a mini project.

## Learning Outcomes

By completing this assignment, I practiced:

- Designing classes and objects
- Applying encapsulation for secure data handling
- Using inheritance to promote code reuse
- Implementing interfaces for abstraction
- Leveraging polymorphism for flexible code design
- Building a small real-world application using OOP principles
